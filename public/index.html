RefineID WebUSB feasibility probe

First milestone only: can an ordinary web page even claim a reader interface? This page enumerates USB descriptors and attempts one interface claim. It never sends APDUs, performs data or control transfers, powers a card, asks for a PIN, signs anything, or reads USB serial numbers. A permission grant is not proof of usable card access.
